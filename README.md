# CabinSwap



A the Long Dark mod that replaces the house at the Cannery Worker Residences in Bleak Inlet with the Mindful Cabin from Forsaken Airfield.





### Features:



* Fully interactable no-loading screen cabin.
* Some changes to the docks outside the cabin for easier movement. (Like a staircase to the fishing hut)
* Custom 20L water storage under the cabinet sink.
* Fully compatible with vanilla safehouse customisation and [SafehouseCustomizationPlus](https://github.com/HAHAYOUDEAD/SafehouseCustomizationPlus) by Waltz





### Proof of concept:

This mod basically turned into a proof of concept on how to move objects from one scene into another.

I created a guide here: [TLD modding: bringing objects from one scene into another /by KanarieWilfried.md](https://cdn.discordapp.com/attachments/1386353992765935647/1553063021494927531/Cross_Scene_Object_Guide.md?ex=6ad0eea6&is=6acf9d26&hm=bf09252ea37194879ac01edaccd9afbc25cb0fa9cb20de1123a4eeffcbe6d747&)



### Installation:



Install MelonLoader by downloading and running [MelonLoader.Installer.exe](https://github.com/HerpDerpinstine/MelonLoader/releases/latest/download/MelonLoader.Installer.exe)

Install the following dependencies in your mods folder:

[ModData](https://github.com/dommrogers/ModData)

Unzip the latest release and drop it in your mods folder.
